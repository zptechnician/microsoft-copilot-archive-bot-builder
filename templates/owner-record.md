# Owner Record — Archive Agent

> README §8.1 — Minimum Owner Record. Copy this file per archive and
> fill in every row. Do not copy another project's source URLs, prompts
> containing confidential names, or approved-user lists into a new agent.

| Record | Value |
| --- | --- |
| Agent name | `[Team or Project] \| Archive Agent` |
| Owner | _Role / name_ |
| Backup owner | _Role / name_ |
| Source path | _Exact SharePoint folder URL_ |
| Audience | _Approved users / security group_ |
| Configuration version | `1.0` |
| Agent instructions version | _Date + commit, e.g. `agent-instructions.md` as of YYYY-MM-DD_ |
| Last QA review | _Date and pilot-test-log location_ |
| Known limitations | _Unsupported file types, inaccessible files, imperfect retrieval, source-priority behavior_ |
| Share link | _Agent link, after pilot gates pass_ |
| Change history | _Date — scope / instruction / permission change — approver — retest result_ |

## Review cadence (README §8.2)

- **At launch:** validate the full pilot matrix and permissions.
- **When source scope or sharing changes:** retest key retrieval and
  access scenarios.
- **After significant archive uploads or reorganization:** verify
  citations and search results again.
- **Periodically:** confirm ownership, audience, and current
  Microsoft 365 behavior; log changes to the template or product UI.
